A tiny program that writes one sentence about a small moment of everyday wonder to a file. The line is 103 characters: an umbrella opened indoors by mistake makes the hallway smell of rain that has not fallen yet.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, no network, deterministic: two runs produce byte-identical output.

## The line

> My umbrella, opened indoors by mistake, made the hallway smell briefly of rain that had not fallen yet.

Thirty-six candidate lines were written from deliberately different angles, the cliches were thrown out, and the survivors were judged pairwise against the brief by four readers — a literalist weighing the real moment, a novelty hunter weighing the unmet angle, a one-read reader weighing how fast the surprise lands, and an editor weighing every word. The umbrella line won the final 2-2 on the brief's criterion order.
